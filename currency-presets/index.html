    Currency presets¶

    The existing four presets (EUR, USD, GBP, JPY) remain unchanged. Twenty additive presets expose the stored Currency fields through Rust, C, Go and Python.

    • Rust: Currency::twd(), Currency::chf(), and the other lowercase codes.
    • Python: itofin.indexes.Currency.twd(), .chf(), and the other lowercase codes.
    • TRY uses Currency::try_() / Currency.try_() because try is reserved.
    • Go: session.TWD(), session.CHF(), and the other uppercase codes. Close currencies and sessions explicitly; currency handles remain session-owned.
    • C: itofin_currency_new keeps selectors 0 EUR, 1 USD, 2 GBP, 3 JPY. The table below lists additive selectors 4 through 23. Release each handle.

    All six fields are core value data. Equality remains name-based, so Taiwan dollar is not interchangeable with the colloquial New Taiwan Dollar name. No existing constructor, inspector, equality, rounding or triangulation behavior is changed. The Currency constructor and stored-field accessor bindings are a separate additive slice; these presets simply return those same value objects.

    Exact source provenance¶

    Values were extracted from the local QuantLib source at revision 9863b578af0caa4cecabf697196533e84a8308b6, whose ql/version.hpp declares 1.43-dev. Each of the five source files matched its committed Git blob byte-for-byte before extraction. An unrelated dirty workflow file was not modified. This is pinned source data, not a claim of a compiled QuantLib execution or the latest ISO display/cash convention. No external wheel supplied these fields.

    The four identical currency_presets.tsv test fixtures retain all six fields, class names, relative source paths and constructor line numbers. Their SHA256 is 74cf061619d4600a580e2e782fd13f50b7154a289b0a336d404cb044acc007b5. The fixtures live in the core tests, C ABI tests, Go testdata and Python fixtures.

    Boundaries¶

    • These are 20 selected presets, not the full QuantLib currency catalogue.
    • No currency rounding, triangulation, minor-unit-code or exchange-rate-manager API is added.
    • C/Go contexts and sessions, thread confinement, explicit release and errors retain the existing binding contract.
